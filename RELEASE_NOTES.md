This release consolidates the frozen EBMUS scientific implementation and reference outputs.

- scoped duplicate/distinct and correction ambiguity handling;
- brute-force / generic LP / generic MILP references;
- controlled exactness and scalability validation;
- point-imputation and interval-baseline comparison;
- evidence-refinement and sensitivity experiments;
- 16-week FreeInference natural evidence analysis;
- TraceLab controlled cross-provider replication;
